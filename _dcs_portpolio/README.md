# 포트폴리오 - 컨테이너 오케스트레이션 & 관제 플랫폼

이 폴더는 입사서류 제출용으로 재구성한 포트폴리오 자료입니다. 실제 작업은 회사 내부 운영 서버에서
진행되었기 때문에, **실제 IP·API 키·DB 접속정보·사내 식별자(장비 ID 등)·업체명은 전부 제거하고
일반화된 이름으로 대체**했습니다. 아키텍처와 문제해결 과정 자체는 실제 작업 내용을 그대로 반영합니다.

## 구성

- [`PORTFOLIO.md`](./PORTFOLIO.md) — 프로젝트 개요, 아키텍처, 핵심 성과 요약 (메인 문서)
- [`CASE_STUDIES.md`](./CASE_STUDIES.md) — 실제로 겪고 해결한 기술적 문제 7가지를 상세히 정리
- [`TECH_STACK.md`](./TECH_STACK.md) — 사용 기술 스택 목록
- [`SECURITY_CHECKLIST.md`](./SECURITY_CHECKLIST.md) — 외부 제출 전 반드시 확인할 체크리스트 (제출 전에 꼭 읽어주세요)

## 제출 전 필수 확인사항

**`SECURITY_CHECKLIST.md`를 먼저 읽어주세요.** 문서 내용 자체는 익명화했지만, 이 폴더 밖에 있는
스크린샷·git 커밋 이력·터미널 로그 등 다른 자료를 함께 제출하시면 실제 사내 정보가 노출될 수 있습니다.
