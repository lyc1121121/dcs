# 변경 이력

DCSManager/DCSServer/DCSAgent 및 연동 시스템(eai_agent/eai_server, JobRadar)의 주요 변경사항을
최신순으로 기록합니다.

## 2026-08-20

- **123단계**: "MariaDB" 배지 옆에 색상이 다른 "JobRadar" 바로가기 탭 추가 (새 탭에서 열림)
- **122단계**: 좌측에 "개요" 탭 신규 추가 — 포트폴리오(작업이력) 내용을 마크다운으로 저장하고
  화면에서 직접 보기/수정 가능, 아키텍처·기술스택 다이어그램 이미지 포함
- **120단계**: 바로가기 링크(모니터링/Registry/Advisor/NodeExporter/MariaDB)가 사내 LAN
  IP(172.30.1.54)로 하드코딩돼 있어 Tailscale로만 접속하는 환경에서 열리지 않던 문제를
  100.125.13.91(Tailscale IP)로 수정
- **117~119단계**: JobRadar에 "공무직" 탭 신규 추가 — saramin 일반 키워드 검색으로 직종 제한 없이
  수집, 8일 이내 등록 공고를 건수 제한 없이 최신순 표시, 화면 자동 폴링(30~360분 설정 가능)을
  클라이언트 타이머에서 서버 스케줄러(APScheduler) 캐시 방식으로 전환, 등록일시 표시를
  "8월13일 등록 (35시간)" 형식으로 변경. 뒤이어 안양시청 "채용공고(공공기관 및 협력기관)"
  게시판을 수집하는 "안양 공공기관" 탭도 동일한 패턴으로 추가
- **116단계**: 입사서류 제출용 포트폴리오 자료 작성 (시스템 아키텍처, 트러블슈팅 사례 7건,
  기술스택 — 실제 사내 정보는 익명화)

## 2026-08-18

- **115단계**: eai_server 파일 일련번호를 날짜가 바뀌면 00001로 재시작하도록 변경, 업로드 파일의
  날짜를 오늘 날짜로 치환해서 outbox에 저장
- **114단계**: RCV 방향 테스트 업로드에 J/I 파일 매핑 추가, eai_server로 전달된 outbox 파일은
  삭제 대신 보관하도록 변경

## 2026-08-17

- eai_agent/eai_server 프로젝트를 저장소에 추가
- **110단계**: DCS 컨테이너 기동/정지 시 카카오톡으로 알림 전송 (OAuth2 스타일 토큰 자동 갱신,

- **108단계**: DCSManager 진입 시 로그인 화면 없이 바로 접근 가능하도록 변경 (내부망 전용이므로)
