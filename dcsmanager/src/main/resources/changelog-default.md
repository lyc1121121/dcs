# 변경 이력

DCSManager/DCSServer/DCSAgent 및 연동 시스템(eai_agent/eai_server, JobRadar)의 주요 변경사항을
최신순으로 기록합니다.

## 2026-08-29

- **158단계**: PRIVATE 탭에 "파일탐색기" 추가(로그아웃 버튼 왼쪽) - 실제 CentOS 서버의
  /working 폴더를 파일질라처럼 폴더 이동 + 파일 클릭해서 내용(텍스트/이미지) 확인 가능,
  조회 전용(쓰기/삭제 없음). 이를 위해 dcsmanager-test-tomcat 컨테이너에 호스트 /working을
  읽기전용으로 마운트함(전체 서버가 아니라 /working 범위만 - 사용자 확인 후 진행).
  서버측에서 마운트 루트 밖으로 못 벗어나게 경로 검증 처리, 미인증 접근 차단,
  경로조작(../) 시도 차단까지 테스트로 확인함
- **156단계**: TMSManager "TMS 컨테이너"/"기타 컨테이너" 표에도(135/136단계에서 JobRadar에
  넣었던 것과 동일하게) 컬럼 헤더 클릭 정렬 추가 - 클릭하면 오름차순/내림차순 토글(▲/▼),
  "삭제"/"관리" 컬럼은 정렬 대상에서 제외. 목록이 5초마다 자동 새로고침돼도 선택한 정렬
  상태가 유지됨(서버 렌더링 결과를 클라이언트에서 재정렬)
- **155단계**: JobRadar "관심" 체크를 브라우저 localStorage 대신 서버 DB(favorites
  테이블)에 저장하도록 변경 - 136단계 방식은 체크한 브라우저에서만 보이고 다른 컴퓨터/
  브라우저로 접속하면 사라지는 문제가 있었음. 이제 페이지를 열 때 서버에서 전체 목록을
  받아오고, 체크/해제 시마다 서버에 반영되어 어디서 접속해도 동일하게 보임(완전히 분리된
  브라우저 컨텍스트로 교차 확인 완료)

  Prometheus 쿼리(name=~"^dcs1300100.*" 등)는 그대로 유지 - 실제 컨테이너명이 안 바뀌었으므로
- **151단계**: 화면에 보이는 문구 중 "DCS"를 "TMS"로 변경(대소문자 유지: DCS→TMS,
  dcs→tms) - 브라우저 타이틀("DCSManager"→"TMSManager"), 탭/버튼/테이블 헤더("DCS_ID"→
  "TMS_ID" 등), 폼 라벨과 안내문구, 확인창/에러/완료 메시지 전부 적용. 실제 서버 구성은
  그대로 유지 - 도커 컨테이너 실제 이름(dcs1300100090 등), DB 컬럼/필드명, HTML id/name
  속성, API 경로, 관련 실제 서비스명(DCSServer/DCSAgent)은 변경하지 않음(화면 표시 문구만
  변경한다는 요청 취지에 따름). 폼 라벨의 "DCS2TerminalX.jar" 등 실제 파일명 언급도
  그대로 둠(실제 파일명이 안 바뀌었으므로)
- JobRadar "메모" 탭에 글자 서식(굵게/기울임/밑줄/색상 변경) 툴바와 이미지 붙여넣기
