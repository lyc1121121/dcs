                            개요

                            Raspberry Pi는 Hailo NPU(신경망 처리 장치)를 통해 AI 가속을 지원합니다. 이 전용 칩은 CPU보다 훨씬 효율적으로 AI 추론을 처리해, 실시간 비전 작업과 언어 모델 구동을 가능하게 합니다.

                            하드웨어 옵션

                            Raspberry Pi 5에 연결할 수 있는 AI 가속기 3종:

                            1. AI Kit — Hailo-8L NPU가 사전 장착된 M.2 HAT+ (현재 단종)
                            2. AI HAT+ — 온보드 Hailo-8L NPU
                            3. AI HAT+ 2 — 온보드 Hailo-10H NPU(비전 AI와 LLM 모두 지원)

                            하드웨어 준비물

                            • 64비트 Raspberry Pi OS(Trixie)를 구동하는 Raspberry Pi 5
                            • 위 Hailo AI 가속기 중 하나
                            • 비전 AI용: Raspberry Pi Camera Module 3 등 지원 카메라

                            소프트웨어 설정 단계

                            1. PCIe Gen 3.0 활성화 (AI Kit 전용)

                            sudo raspi-config

                            Advanced Options > PCIe Speed에서 Gen 3.0 모드를 켭니다. 또는 /boot/firmware/config.txt에 아래를 추가합니다.

                            dtparam=pciex1_gen=3

                            2. 시스템 업데이트

                            sudo apt update
sudo apt full-upgrade -y
sudo rpi-eeprom-update -a
sudo reboot

                            3. 의존성 설치

                            AI Kit 또는 AI HAT+:

                            sudo apt install dkms
sudo apt install hailo-all

                            AI HAT+ 2:

                            sudo apt install dkms
sudo apt install hailo-h10-all

                            4. 설치 확인

                            sudo reboot
hailortcli fw-control identify

                            정상적으로 설치되면 펌웨어 버전과 장치 정보가 출력됩니다.

                            비전 AI 모델

                            sudo apt update && sudo apt install rpicam-apps
rpicam-hello

                            객체 탐지 예시

                            모델명령
                            YOLOv6rpicam-hello -t 0 --post-process-file /usr/share/rpi-camera-assets/hailo_yolov6_inference.json
                            YOLOv8rpicam-hello -t 0 --post-process-file /usr/share/rpi-camera-assets/hailo_yolov8_inference.json

                            이미지 분할(Segmentation)

                            rpicam-hello -t 0 --post-process-file /usr/share/rpi-camera-assets/hailo_yolov5_segmentation.json --framerate 20

                            자세 추정(Pose Estimation)

                            rpicam-hello -t 0 --post-process-file /usr/share/rpi-camera-assets/hailo_yolov8_pose.json

                            LLM (AI HAT+ 2 전용)

                            Hailo Ollama 서버 설치

                            sudo dpkg -i hailo_gen_ai_model_zoo_5.1.1_arm64.deb

                            서버 시작

                            hailo-ollama

                            사용 가능한 모델 목록

                            curl --silent http://localhost:8000/hailo/v1/list

                            모델 다운로드

                            curl --silent http://localhost:8000/api/pull \
  -H 'Content-Type: application/json' \
  -d '{"model": "qwen2:1.5b", "stream": true}'

                            LLM에 질의하기

                            curl --silent http://localhost:8000/api/chat \
  -H 'Content-Type: application/json' \
  -d '{"model": "qwen2:1.5b", "messages": [{"role": "user", "content": "질문 내용"}]}'

                            선택 사항: 웹 인터페이스(Open WebUI)

                            Docker를 설치한 뒤 Open WebUI 컨테이너를 배포합니다.

                            docker run -d -e OLLAMA_BASE_URL=http://127.0.0.1:8000 \
  -v open-webui:/app/backend/data --name open-webui \
  --network=host --restart always \
  ghcr.io/open-webui/open-webui:main

                            접속 주소: http://127.0.0.1:8080
