                            Compute Module이란?

                            Raspberry Pi Compute Module은 "임베디드/산업용 애플리케이션을 위해 설계된, 표준 Raspberry Pi 싱글보드 컴퓨터(SBC)의 소형 버전"입니다. 일반 Raspberry Pi 보드와 달리 HDMI, USB, 이더넷 같은 표준 커넥터가 없어, 커스텀 시스템에 통합하기에 적합합니다.

                            이 모듈들은 "시스템온모듈(SoM) 형태"로, "디지털 사이니지, 씬 클라이언트, 공정 자동화 같은 산업·상업용 애플리케이션"을 대상으로 합니다.

                            IO 보드와의 관계

                            Compute Module이 동작하려면 Compute Module IO 보드(CMIO)라는 캐리어 보드가 필요합니다. IO 보드는 전원 공급, GPIO 핀을 표준 헤더로 노출, 카메라/디스플레이 인터페이스 제공, HDMI·USB·네트워킹 표준 커넥터 제공 등 필수 연결성을 담당합니다.

                            문서에 따르면 IO 보드는 "독립 제품으로 사용해 빠른 프로토타이핑과 임베디드 시스템 개발에 활용하거나, 자체 캐리어(IO) 보드를 설계할 때 참고용 레퍼런스 디자인으로 사용"할 수 있습니다.

                            현재 모델

                            모델프로세서RAM 옵션저장공간폼팩터
                            CM5(2024)BCM27122~16GB0~64GB eMMC듀얼 100핀 커넥터
                            CM4S(2022)BCM27111~8GB0~64GB eMMCDDR2 SODIMM
                            CM4(2020)BCM27111~8GB0~64GB eMMC듀얼 100핀 커넥터
                            CM3+(2019)BCM2837B01GB0~64GB eMMCDDR2 SODIMM

                            최신 모델인 CM5는 Raspberry Pi 5의 구성요소와 온보드 플래시 저장공간 옵션을 결합해, 새로운 산업용 설계의 현재 표준으로 자리잡고 있습니다.

                            eMMC에 이미지 플래시하기

                            호스트 컴퓨터에서 USB를 통해 Compute Module의 eMMC 저장장치에 OS 이미지를 기록하는 방식입니다. 해당 IO 보드, USB 케이블, rpiboot나 Raspberry Pi Imager 같은 소프트웨어가 필요합니다.

                            IO 보드 준비 — Compute Module을 해당 IO 보드에 연결합니다. CM5IO의 경우 nRPI_BOOT 점퍼를 J2에 꽂고, USB-C 슬레이브 포트를 호스트 컴퓨터에 연결합니다.

                            이미지 플래시 — 호스트에서 rpiboot를 실행해 Compute Module이 대용량 저장장치로 인식되면 아래 명령으로 기록합니다.

                            sudo dd if=raw_os_image.img of=/dev/sdX bs=4MiB

                            eMMC로 부팅 — IO 보드의 점퍼에서 nRPI_BOOT를 J2에서 분리(eMMC 부팅 비활성화 해제)한 뒤 전원을 다시 연결하면 방금 플래시한 이미지로 부팅됩니다.

                            EEPROM 부트로더 설정

                            CM4 이후 Compute Module은 부팅 파티션에 저장된 펌웨어 대신 EEPROM 부트로더를 사용합니다. 특정 부트로더 릴리스를 선택하고, 부팅 장치 순서를 설정하고, 쓰기 방지를 활성화하는 것이 권장 사항입니다.

                            부트로더 플래시 — eMMC 플래시와 동일하게 하드웨어를 준비하되 EEPROM_nWP가 로우로 당겨져 있지 않은지 확인한 뒤 실행합니다.

                            ./rpiboot -d recovery

                            설정 변경 — boot.conf 파일을 편집해 BOOT_ORDER를 설정합니다(예: 네트워크 부팅은 0xf2, SD/eMMC는 0xf1, NVMe는 0xf6). update-pieeprom.sh를 실행한 뒤 아래 명령으로 플래시합니다.

                            ../rpiboot -d .
