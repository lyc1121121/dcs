config.txt란?

config.txt는 일반 PC의 BIOS를 대신하는 Raspberry Pi의 설정 방식입니다. "GPU는 Arm CPU와 리눅스가 초기화되기 전에 config.txt를 읽습니다." /boot/firmware/의 부팅 파티션에 위치하며, 단순한 속성=값 형식을 사용하고, 변경사항은 재부팅 후에만 적용됩니다.

파일 형식

한 줄에 하나의 property=value 문장을 쓰고, 주석은 #으로 표시합니다. 한 줄은 98자로 제한됩니다.

# 오디오 활성화(snd_bcm2835 로드)
dtparam=audio=on

# 감지된 카메라에 대해 오버레이 자동 로드
camera_auto_detect=1

# DRM VC4 V3D 드라이버 활성화
dtoverlay=vc4-kms-v3d

주요 디스플레이 옵션

hdmi_enable_4kp60 — 일부 Raspberry Pi 4 모델에서 4K 모니터의 60Hz 주사율을 활성화합니다. 다만 "전력 소모와 발열이 증가"합니다.

주요 하드웨어 설정 옵션

camera_auto_detect / display_auto_detect — 활성화하면 "펌웨어가 인식된 CSI 카메라"와 DSI 디스플레이에 대해 자동으로 오버레이를 로드합니다. Raspberry Pi OS에서는 기본적으로 켜져 있습니다.

dtoverlay — 특정 하드웨어 기능에 대한 커널 지원을 활성화하는 디바이스 트리 오버레이를 펌웨어가 로드하도록 요청합니다. 예: dtoverlay=vc4-kms-v3d는 그래픽 드라이버를 활성화합니다.

dtparam — I2C, SPI 같은 인터페이스에 대한 디바이스 트리 매개변수를 적용하며, 오버레이 설정과 함께 자주 사용됩니다.

부팅 설정

kernel — 로드할 커널 파일을 지정합니다. 모델마다 기본값이 다르며, 최신 Raspberry Pi 5는 해당 시스템에 최적화된 kernel_2712.img를 선호합니다.

arm_64bit — 1로 설정하면 64비트 모드로 부팅합니다. Pi 4 이상에서는 기본값이 1입니다(64비트만 지원하는 모델 제외).

cmdline — 대체 커널 커맨드라인 파일을 지정합니다(기본값: cmdline.txt).

disable_splash — 1로 설정하면 부팅 시 무지개 스플래시 화면이 사라집니다.

GPIO 제어

gpio 지시자로 부팅 시 핀 상태를 설정할 수 있습니다.

# GPIO12를 출력으로, high 상태로 설정
gpio=12=op,dh

# 17~21번 핀을 입력으로 설정
gpio=17-21=ip

입출력 모드(ip/op), 대체 기능(a0~a5), 풀업/풀다운(pu/pd) 등의 속성을 지원합니다.
