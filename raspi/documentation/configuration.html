                            설정 방법 3가지

                            1. 데스크탑 GUI — 디스플레이가 있는 사용자를 위한 Control Centre 시각적 인터페이스
                            2. raspi-config(터미널 메뉴) — 세밀한 제어가 가능한 텍스트 기반 대화형 메뉴
                            3. 직접 CLI 편집 — 설정 파일을 수동으로 편집하거나 커맨드라인 사용

                            오디오/영상 출력

                            오디오 설정

                            HDMI, 3.5mm 헤드폰 잭, USB 오디오 장치 중에서 선택할 수 있습니다. 기본은 첫 번째 HDMI 장치이며, 필요 시 헤드폰 잭이나 USB로 자동 전환됩니다.

                            wpctl status
wpctl set-default <ID>

                            디스플레이 설정

                            • Pi Zero/Zero 2W: mini HDMI 1개, 최대 1920×1080
                            • Pi 4B/400/CM4: micro HDMI 2개, 4K@30Hz 듀얼 또는 4K@60Hz 단일
                            • Pi 5/500/500+/CM5: micro HDMI 2개, 4K@60Hz 듀얼

                            콘솔 모드 디스플레이는 /boot/firmware/cmdline.txt의 커널 파라미터로 설정합니다.

                            video=<display>:<width>x<height>M@<refresh_rate>
# 예: video=HDMI-A-1:1920x1080M@60

                            화면 꺼짐(Screen Blanking)

                            기본 10분 동안 조작이 없으면 꺼지도록 설정 가능합니다. cmdline.txt에 consoleblank=600처럼 초 단위로 지정합니다.

                            네트워킹

                            호스트명 설정

                            호스트명을 설정하면 mDNS로 pi@my-pi.local처럼 접속할 수 있습니다. 영문 소문자, 숫자, 하이픈만 사용 가능합니다.

                            DHCP vs 고정 IP

                            기기에 고정 IP를 직접 설정하기보다, 잘못된 설정이나 접속 장애를 피하기 위해 공유기에서 DHCP 예약을 하는 방식을 권장합니다.

                            네트워크 우선순위

                            우선순위 숫자가 높을수록 먼저 연결됩니다. 0은 중립, 음수는 가장 낮은 우선순위입니다.

                            # 우선순위 확인
nmcli --fields AUTOCONNECT-PRIORITY,NAME connection

# 우선순위 설정
sudo nmcli connection modify "Network Name" connection.autoconnect-priority 10

                            무선 연결

                            WLAN 국가 설정

                            "듀얼밴드 무선을 갖춘 Raspberry Pi 기기는, 안전을 위해 WLAN 국가(Country)를 설정하기 전까지는 네트워킹이 자동으로 비활성화됩니다." 올바른 주파수 대역 선택을 위해 반드시 필요합니다.

                            네트워크 찾기

                            nmcli dev wifi list

                            네트워크 연결

                            WEP, WPA, WPA2, WPA3를 지원합니다. 숨겨진 네트워크는 "숨겨진 무선 네트워크에 연결" 메뉴에서 수동으로 입력합니다.

                            시스템 및 지역화

                            시간대, 로케일, 키보드 배열 등을 데스크탑 GUI 또는 raspi-config로 설정합니다. 날짜/시간 표기와 언어 관련 동작을 결정합니다.

                            sudo raspi-config

                            5 Localisation Options 메뉴에서 시간대/로케일/키보드를 설정합니다.

                            사용자 접근 관리

                            사용자 계정 생성, 비밀번호 변경, sudo 권한을 다룹니다. 최초 설정 시 구성되지만 이후에도 시스템 도구로 변경할 수 있습니다.

                            sudo raspi-config

                            1 System Options > S3 Password에서 비밀번호를 변경합니다.

                            하드웨어 통신

                            주변장치와 통신하기 위한 I2C, SPI, 시리얼 인터페이스를 설정합니다. 센서, 디스플레이 등 하드웨어와 통신할 때 필요합니다.

                            sudo raspi-config

                            3 Interface Options에서 I2C/SPI/시리얼을 켜고 끌 수 있습니다.

                            성능

                            CPU 클럭 스케일링, 메모리 할당 등 성능 튜닝 옵션입니다. 처리 성능과 발열 관리 사이의 균형을 조절합니다.

                            sudo raspi-config

                            6 Advanced Options에서 관련 설정에 접근할 수 있습니다.

                            LED 동작

                            전원 LED/활동 LED가 언제 어떻게 켜질지 설정합니다(예: 헤드리스로 운용할 때 LED를 꺼서 절전하는 용도로도 사용).

                            부팅 동작

                            자동 로그인 여부와 부팅 시 스플래시 화면 표시 여부를 관리합니다. 헤드리스 부팅 구성 옵션도 포함됩니다.

                            펌웨어

                            부트로더와 EEPROM 업데이트를 통해 시스템 안정성을 유지하고 새 기능 지원을 추가합니다.

                            sudo apt update
sudo rpi-eeprom-update -a
sudo reboot

                            외부 저장장치

                            기본 SD카드 대신 USB 드라이브, NVMe SSD, 네트워크 저장장치로 부팅할 수 있도록 설정합니다(모델별 지원 범위가 다르니 하드웨어 문서 참고).

                            Raspberry Pi 스토어

                            Raspberry Pi에 관한 모든 것을 만날 수 있는 케임브리지의 원스톱 매장.

                            Raspberry Pi 이벤트

                            Raspberry Pi를 직접 만나거나, 가까운 커뮤니티 이벤트를 찾아보세요.
