설정 방법 3가지

  1. 데스크탑 GUI — 디스플레이가 있는 사용자를 위한 Control Centre 시각적 인터페이스
  2. raspi-config(터미널 메뉴) — 세밀한 제어가 가능한 텍스트 기반 대화형 메뉴
  3. 직접 CLI 편집 — 설정 파일을 수동으로 편집하거나 커맨드라인 사용

오디오/영상 출력

오디오 설정

HDMI, 3.5mm 헤드폰 잭, USB 오디오 장치 중에서 선택할 수 있습니다. 기본은 첫 번째 HDMI 장치이며, 필요 시 헤드폰 잭이나 USB로 자동 전환됩니다.

wpctl status
wpctl set-default <ID>

디스플레이 설정

  • Pi Zero/Zero 2W: mini HDMI 1개, 최대 1920×1080
  • Pi 4B/400/CM4: micro HDMI 2개, 4K@30Hz 듀얼 또는 4K@60Hz 단일
  • Pi 5/500/500+/CM5: micro HDMI 2개, 4K@60Hz 듀얼

콘솔 모드 디스플레이는 /boot/firmware/cmdline.txt의 커널 파라미터로 설정합니다.

video=<display>:<width>x<height>M@<refresh_rate>
# 예: video=HDMI-A-1:1920x1080M@60

화면 꺼짐(Screen Blanking)

기본 10분 동안 조작이 없으면 꺼지도록 설정 가능합니다. cmdline.txt에 consoleblank=600처럼 초 단위로 지정합니다.

네트워킹

호스트명 설정

호스트명을 설정하면 mDNS로 pi@my-pi.local처럼 접속할 수 있습니다. 영문 소문자, 숫자, 하이픈만 사용 가능합니다.

DHCP vs 고정 IP

기기에 고정 IP를 직접 설정하기보다, 잘못된 설정이나 접속 장애를 피하기 위해 공유기에서 DHCP 예약을 하는 방식을 권장합니다.

네트워크 우선순위

우선순위 숫자가 높을수록 먼저 연결됩니다. 0은 중립, 음수는 가장 낮은 우선순위입니다.

# 우선순위 확인
nmcli --fields AUTOCONNECT-PRIORITY,NAME connection

# 우선순위 설정
sudo nmcli connection modify "Network Name" connection.autoconnect-priority 10

무선 연결

WLAN 국가 설정

"듀얼밴드 무선을 갖춘 Raspberry Pi 기기는, 안전을 위해 WLAN 국가(Country)를 설정하기 전까지는 네트워킹이 자동으로 비활성화됩니다." 올바른 주파수 대역 선택을 위해 반드시 필요합니다.

네트워크 찾기

nmcli dev wifi list

네트워크 연결

WEP, WPA, WPA2, WPA3를 지원합니다. 숨겨진 네트워크는 "숨겨진 무선 네트워크에 연결" 메뉴에서 수동으로 입력합니다.

그 외 설정 항목

이 가이드는 이 외에도 시스템 지역화, 사용자 접근 관리, 원격 접속 설정, 하드웨어 통신 인터페이스(I2C/SPI/UART), 성능 튜닝, LED 동작 커스터마이즈, 부팅 동작 설정까지 다루며, 전부 위 3가지 방법 중 하나로 접근할 수 있습니다.
