                            개요

                            Raspberry Pi는 "데스크탑 컴퓨터"로도, "헤드리스(원격) 컴퓨터"로도 쓸 수 있는 소형 컴퓨터입니다. 싱글보드 컴퓨터, Zero 시리즈, 키보드 컴퓨터, Compute Module, Pico 마이크로컨트롤러 등 여러 라인업으로 제공됩니다.

                            하드웨어 준비물

                            부팅 미디어

                            Raspberry Pi는 운영체제 이미지를 담은 비휘발성 저장장치가 필요합니다. 가장 흔한 것은 microSD 카드이며, 최신 모델은 USB 대용량 저장장치, 네트워크 부팅(PXE), PCIe 경유 NVMe도 지원합니다.

                            권장 최소 저장 용량 — Raspberry Pi OS(데스크탑): 32GB / Full: 32GB / Lite(헤드리스): 8GB

                            최대 지원 용량: 2TB 미만(MBR 한계). Raspberry Pi Zero, 초기형 Raspberry Pi, BCM2836 탑재 초기 Pi 2는 부팅 파티션이 256GB로 제한됩니다.

                            주변기기

                            입력장치: USB 포트로 유/무선 키보드·마우스 연결(Raspberry Pi Zero는 micro USB OTG 어댑터 필요). USB 블루투스 동글이나 내장 블루투스 페어링도 지원됩니다.

                            공식 Raspberry Pi 키보드나 키보드 컴퓨터를 사용 중이라면, 뒷면의 USB 포트 중 하나에 유선 마우스를 연결할 수 있습니다. 이렇게 하면 Raspberry Pi 본체의 USB 포트를 더 많이 남겨둘 수 있습니다.

                            Raspberry Pi Zero의 USB 장치

                            Raspberry Pi Zero 모델은 풀사이즈 USB 대신 micro USB를 사용하므로 micro USB OTG 어댑터가 필요합니다. micro USB 포트 중 하나는 "PWR IN"이라고 표시되어 있고 전원 입력 전용이며, "USB"라고 표시된 포트는 어느 것이든 사용할 수 있습니다.

                            Raspberry Pi Zero는 키보드와 마우스를 동시에 사용할 만큼 충분한 전력을 공급하지 못합니다(키보드에 내장 터치패드가 있는 경우는 예외). 그래서 Raspberry Pi Zero에 연결한 micro USB OTG 어댑터에 전원이 공급되는(powered) USB 허브를 꽂고, 그 허브에 마우스를 연결해야 합니다.

                            참고

                            이미 부팅된 Raspberry Pi Zero에 USB 장치를 꽂으면 전압이 순간적으로 떨어져 CPU가 재부팅될 수 있습니다. 그러므로 전원이 공급되는 USB 허브를 사용하거나, 부팅하기 전에 USB 장치를 미리 연결해두는 것을 권장합니다.

                            무선 입력 장치

                            무선 키보드나 마우스를 사용하고 싶다면, 유선 키보드·마우스로 먼저 Raspberry Pi를 설정하고 조립을 마친 뒤에 설정하는 것을 권장합니다. 그런 다음 아래 중 하나를 사용할 수 있습니다.

                            • USB 블루투스 동글이 있는 키보드나 마우스 — 동글을 Raspberry Pi의 USB 포트에 꽂아 연결합니다.
                            • 블루투스가 내장된 키보드나 마우스 — Raspberry Pi 모델이 블루투스를 지원한다면 페어링해서 연결합니다.

                            설정 방법은 환경 설정 문서의 블루투스 주변장치 연결 안내를, 블루투스가 내장된 Raspberry Pi 모델 목록은 이 페이지의 네트워킹 절을 참고하세요.

                            출력장치(디스플레이와 오디오)

                            Raspberry Pi를 데스크탑 컴퓨터로 설정하는 경우, 화면을 보기 위한 디스플레이가 필요합니다. 추가로 스피커나 헤드폰을 연결해 오디오를 출력할 수도 있습니다. 공식 Raspberry Pi 모니터를 사용한다면, 모니터 뒷면의 3.5mm 오디오 잭을 통해 스피커나 헤드폰을 연결할 수 있습니다.

                            모델디스플레이 출력필요 케이블
                            Pi 5, 400, 500, 500+micro-HDMI ×2micro-HDMI → HDMI 케이블
                            Pi 4Bmicro-HDMI ×2 + 3.5mm TRRSmicro-HDMI → HDMI 케이블
                            Pi 3 (전체)HDMI + 3.5mm TRRS표준 HDMI 케이블
                            Pi Zero (전체)mini HDMImini-HDMI → HDMI 케이블

                            오디오 출력은 모델에 따라 HDMI, USB, 블루투스, 3.5mm 잭 중에서 선택할 수 있습니다.

                            전원 공급 장치

                            모델전압/전류공식 어댑터
                            Pi 500+5V @ 5A27W USB-C
                            Pi 5 & 5005V @ 5A27W USB-C
                            Pi 4B & 4005V @ 3A15W USB-C
                            Pi 3 (전체)5V @ 2.5A12.5W Micro USB
                            Pi 25V @ 2.5A12.5W Micro USB
                            Pi 1 (전체)5V @ 2.5A12.5W Micro USB
                            Pi Zero (전체)5V @ 2.5A12.5W Micro USB

                            네트워킹

                            모델무선이더넷
                            Pi 3B+ 이상듀얼밴드 Wi-Fi(2.4/5GHz)있음(4B+는 기가비트)
                            Pi 3B2.4GHz만있음
                            Pi 3A+듀얼밴드 Wi-Fi없음
                            모든 키보드 컴퓨터듀얼밴드 Wi-Fi기가비트 이더넷
                            Pi Zero W/2W2.4GHz만없음

                            Raspberry Pi 설정하기

                            데스크탑으로 설정

                            1단계 — Raspberry Pi Imager로 OS 설치, 호스트명·지역화·사용자 계정·Wi-Fi·원격접속까지 함께 설정하며 부팅 미디어를 준비합니다.

                            2단계 — 키보드·마우스·디스플레이 등 주변기기를 연결합니다.

                            3단계 — 부팅 미디어를 꽂은 뒤 USB-C(구형은 micro USB)로 전원을 연결합니다.

                            4단계 — (선택) Wi-Fi 또는 이더넷 케이블로 네트워크에 연결합니다.

                            헤드리스(원격) 설정

                            최초 부팅 시 네트워크 연결과 SSH 또는 Raspberry Pi Connect를 통한 원격 접속이 필요합니다.

                            1단계 — Imager로 부팅 미디어 준비 시: Raspberry Pi OS Lite 권장, 네트워크 설정, 원격 접속 설정, 사용자 계정을 함께 구성.

                            2단계 — 전원 연결

                            3단계 — Wi-Fi 또는 이더넷으로 네트워크 연결

                            4단계 — SSH 또는 Raspberry Pi Connect로 원격 접속

                            수동 SSH 설정 대안: 부팅 파티션에 ssh 파일과, <username>:<encrypted-password> 형식의 userconf.txt 파일을 만듭니다. 암호화된 비밀번호는 아래 명령으로 생성합니다.

                            openssl passwd -6

                            부팅 미디어에 OS 설치하기

                            Imager로 설치

                            1단계: Imager 설치 및 실행 — Raspberry Pi 웹사이트에서 Windows/Mac/Linux용을 받거나, Raspberry Pi OS에서는 아래 명령으로 설치합니다.

                            sudo apt install rpi-imager

                            2단계: 기본 항목 설정 — 기기 모델 선택 → 운영체제 선택 → 저장장치 선택 → 다음 단계로 진행.
