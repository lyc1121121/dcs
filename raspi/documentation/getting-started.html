개요

Raspberry Pi는 "데스크탑 컴퓨터"로도, "헤드리스(원격) 컴퓨터"로도 쓸 수 있는 소형 컴퓨터입니다. 싱글보드 컴퓨터, Zero 시리즈, 키보드 컴퓨터, Compute Module, Pico 마이크로컨트롤러 등 여러 라인업으로 제공됩니다.

하드웨어 준비물

부팅 미디어

Raspberry Pi는 운영체제 이미지를 담은 비휘발성 저장장치가 필요합니다. 가장 흔한 것은 microSD 카드이며, 최신 모델은 USB 대용량 저장장치, 네트워크 부팅(PXE), PCIe 경유 NVMe도 지원합니다.

권장 최소 저장 용량 — Raspberry Pi OS(데스크탑): 32GB / Full: 32GB / Lite(헤드리스): 8GB

최대 지원 용량: 2TB 미만(MBR 한계). Raspberry Pi Zero, 초기형 Raspberry Pi, BCM2836 탑재 초기 Pi 2는 부팅 파티션이 256GB로 제한됩니다.

주변기기

입력장치: USB 포트로 유/무선 키보드·마우스 연결(Raspberry Pi Zero는 micro USB OTG 어댑터 필요). USB 블루투스 동글이나 내장 블루투스 페어링도 지원됩니다.

오디오 출력은 모델에 따라 HDMI, USB, 블루투스, 3.5mm 잭 중에서 선택할 수 있습니다.

Raspberry Pi 설정하기

데스크탑으로 설정

1단계 — Raspberry Pi Imager로 OS 설치, 호스트명·지역화·사용자 계정·Wi-Fi·원격접속까지 함께 설정하며 부팅 미디어를 준비합니다.

2단계 — 키보드·마우스·디스플레이 등 주변기기를 연결합니다.

3단계 — 부팅 미디어를 꽂은 뒤 USB-C(구형은 micro USB)로 전원을 연결합니다.

4단계 — (선택) Wi-Fi 또는 이더넷 케이블로 네트워크에 연결합니다.

헤드리스(원격) 설정

최초 부팅 시 네트워크 연결과 SSH 또는 Raspberry Pi Connect를 통한 원격 접속이 필요합니다.

1단계 — Imager로 부팅 미디어 준비 시: Raspberry Pi OS Lite 권장, 네트워크 설정, 원격 접속 설정, 사용자 계정을 함께 구성.

2단계 — 전원 연결

3단계 — Wi-Fi 또는 이더넷으로 네트워크 연결

4단계 — SSH 또는 Raspberry Pi Connect로 원격 접속

수동 SSH 설정 대안: 부팅 파티션에 ssh 파일과, <username>:<encrypted-password> 형식의 userconf.txt 파일을 만듭니다. 암호화된 비밀번호는 아래 명령으로 생성합니다.

openssl passwd -6

부팅 미디어에 OS 설치하기

Imager로 설치

1단계: Imager 설치 및 실행 — Raspberry Pi 웹사이트에서 Windows/Mac/Linux용을 받거나, Raspberry Pi OS에서는 아래 명령으로 설치합니다.

sudo apt install rpi-imager

2단계: 기본 항목 설정 — 기기 모델 선택 → 운영체제 선택 → 저장장치 선택 → 다음 단계로 진행.
