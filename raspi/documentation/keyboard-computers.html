                            개요

                            Raspberry Pi는 완전한 컴퓨터를 키보드 폼팩터에 통합한 3가지 모델을 제공합니다.

                            • Raspberry Pi 400(2020) — Raspberry Pi 4 기반, 4GB RAM
                            • Raspberry Pi 500(2024) — Raspberry Pi 5 기반, 8GB RAM
                            • Raspberry Pi 500+(2025) — Raspberry Pi 5 기반, 16GB RAM

                            키보드 컴퓨터 키트 구성품

                            Raspberry Pi 400 키트 — Raspberry Pi 400 키보드 컴퓨터, 15W USB-C 전원 공급 장치, USB 마우스, Raspberry Pi OS가 미리 설치된 16GB microSD 카드, micro-HDMI 케이블, 입문자 가이드북

                            Raspberry Pi 500 키트 — Raspberry Pi 500 키보드 컴퓨터, 27W USB-C 전원 공급 장치, USB 마우스, Raspberry Pi OS가 미리 설치된 32GB A2등급 microSD 카드, micro-HDMI 케이블, 입문자 가이드북

                            Raspberry Pi 500+ 키트 — Raspberry Pi OS가 미리 설치된 SSD를 포함한 Raspberry Pi 500+ 키보드 컴퓨터, 27W USB-C 전원 공급 장치, USB 마우스, micro-HDMI 케이블, M.2 SSD 분해용 스퍼저(개봉 도구), 키캡 풀러, 입문자 가이드북

                            Pi 500+만의 특징

                            기계식 키보드 — "Raspberry Pi 500+의 각 키캡 아래에는 저마다의 기계식 스위치가 있습니다", Cherry MX 스템과 호환되는 Gateron KS-33 스위치를 사용합니다.

                            • DSA 또는 Cherry 프로파일의 교체용 키캡 권장
                            • 7가지 프리셋을 지원하는 RGB 백라이트(Off, Solid White, Solid Color, Gradient, Pinwheel, Heatmap, Reactive)
                            • Vial QMK 펌웨어를 통한 LED 설정
                            • 즉석에서 키 재배치 가능
                            • 교체 가능한 M.2 SSD(2230/2242/2260/2280 폼팩터 지원)

                            백라이트 단축키 — 프리셋 순환: Fn+F4(정방향)/Fn+Shift+F4(역방향), 색상 변경: Fn+F3(16색), 밝기 조절: Fn+F5(감소)/Fn+F6(증가)

                            시작하기

                            1. 부팅 미디어 준비(microSD 또는 Pi 500+는 미리 설치된 SSD 사용)
                            2. 마우스, micro-HDMI 디스플레이 등 주변기기 연결
                            3. 전원 연결(키보드가 자동으로 켜짐)
                            4. Wi-Fi 또는 이더넷으로 네트워크 연결 설정

                            고급 설정

                            rpi-keyboard-config 도구로 다음을 할 수 있습니다: 속도/채도/색상 파라미터로 커스텀 조명 효과 생성, 프리셋별 시작 애니메이션 설정, 키보드 전체 키 재배치, 개별 LED 백라이트 제어. 펌웨어 소스코드는 GitHub의 "Vial QMK 저장소"에서 확인할 수 있습니다.
