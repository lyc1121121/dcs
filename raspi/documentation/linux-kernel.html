리눅스 커널

소개

"Raspberry Pi 커널은 GitHub에서 관리되며, 업스트림 리눅스 커널보다 업데이트가 다소 늦습니다." Raspberry Pi는 지속적인 업데이트 대신 장기지원(LTS) 릴리스를 통합하며, 메인 저장소에 병합하기 전에 테스트를 거칩니다.

커널 빌드하기 - 개요

문서는 두 가지 방식을 안내합니다: 네이티브 빌드(Pi 자체의 컴파일러 사용)와 크로스 컴파일(다른 장비에서 Pi용으로 빌드).

핵심 작업 순서

1. 커널 소스 다운로드

sudo apt install git
git clone --depth=1 https://github.com/raspberrypi/linux

2. 빌드 의존성 설치

sudo apt install bc bison flex libssl-dev make

3. 커널 설정 — 사용 중인 아키텍처와 모델에 맞는 설정을 선택합니다(예: 64비트 Pi 4/5는 bcm2711_defconfig).

4. 빌드

# 64비트
make -j6 Image.gz modules dtbs

# 32비트
make -j6 zImage modules dtbs

5. 모듈/커널 설치

sudo make -j6 modules_install
sudo cp arch/arm64/boot/Image.gz /boot/firmware/$KERNEL.img
sudo cp arch/arm64/boot/dts/broadcom/*.dtb /boot/firmware/
sudo reboot

커널 설정 구성

빌드 전에 원하는 기능을 켜고 끌 수 있는 대화형 설정 화면인 make menuconfig를 사용합니다.

커널 패치하기

직접 patch 유틸리티를 쓰거나, mailbox 형식 패치는 Git으로 적용합니다.

커널 헤더

"커널 모듈을 컴파일하려면 리눅스 커널 헤더가 필요합니다."

sudo apt install linux-headers-rpi-v8

기여하기

Raspberry Pi 전용 변경사항은 Raspberry Pi 커널 저장소에 pull request로 제출하고, 일반적인 리눅스 커널 개선사항은 먼저 업스트림에 기여하는 것을 권장합니다.
