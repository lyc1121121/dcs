Raspberry Pi OS

개요

Raspberry Pi OS는 Debian 리눅스 기반의 공식 무료 운영체제입니다. 69,000개가 넘는 Debian 패키지를 지원하며, Debian의 릴리스 주기를 따라 약 2년마다 주요 버전이 나옵니다. 현재 버전은 Debian Trixie 기반이고, 이전 버전은 Debian Bookworm 기반입니다.

설치 방법 & 에디션

Raspberry Pi Imager(Windows/Mac/Linux) 또는 디스크 이미지를 직접 받아 설치합니다. 세 가지 에디션이 있습니다.

  • Desktop(권장) — Chromium, Firefox, VLC, Thonny가 포함된 그래픽 환경
  • Full — Desktop에 LibreOffice, KiCad, Scratch 등 추가 앱 포함
  • Lite — 헤드리스 서버나 구형 모델을 위한 커맨드라인 전용

64비트/32비트 버전이 모두 존재하며, Raspberry Pi 3 이상은 성능과 메모리 처리 면에서 64비트가 더 적합합니다.

소프트웨어/펌웨어 업데이트

표준 업데이트(APT 방식)

일상적인 업데이트에 권장됩니다.

sudo apt update
sudo apt full-upgrade

선행배포 펌웨어(rpi-update)

개발자 전용 — 실험적인 커널/모듈/펌웨어를 내려받습니다. "동작을 보장하지 않으며 불안정성을 유발할 수 있습니다."

sudo rpi-update
sudo reboot

안정 버전으로 되돌리기

sudo apt update
sudo apt install --reinstall raspi-firmware
sudo reboot

패키지 관리

검색: apt-cache search <keyword> · 상세보기: apt-cache show <package-name> · 설치: sudo apt install <package-name>

제거: sudo apt remove <package-name> (설정파일까지 지우려면 sudo apt purge) · 디스크 확인: df -h · 캐시 정리: sudo apt clean

주요 버전 업그레이드

Bookworm→Trixie처럼 주요 버전을 넘어갈 땐 제자리 업그레이드 대신 "새 저장장치에 Raspberry Pi Imager로 클린 설치할 것을 강력히 권장"합니다.

오디오/비디오 재생

VLC가 기본 설치되어 있습니다. 파일관리자에서 더블클릭하거나 커맨드라인으로 재생할 수 있습니다.

vlc video.mp4
vlc --play-and-exit --fullscreen video.mp4
cvlc --play-and-exit audio.mp3   # 헤드리스 모드

오디오 장치 지정(ALSA): cvlc --play-and-exit -A alsa --alsa-audio-device sysdefault:CARD=Headphones audio.mp3

비디오 장치 지정(DRM): cvlc --play-and-exit --drm-vout-display HDMI-A-1 video.mp4

커맨드라인 유틸리티

kmsprint

연결된 모니터가 지원하는 디스플레이 모드를 나열합니다.

kmsprint -m
kmsprint --device=/dev/dri/card1   # Raspberry Pi 5 이상

vcgencmd

GPU 정보 확인 도구

명령용도
vcgencmd version펌웨어 버전
vcgencmd measure_tempSoC 온도
vcgencmd measure_clock armARM 코어 클럭
vcgencmd measure_volts core코어 전압
vcgencmd get_throttled스로틀링 상태
vcgencmd get_config total_mem총 RAM

vclog

GPU 로그를 표시합니다(root 권한 필요).

sudo vclog --msg
sudo vclog --assert

접근성 기능

  • Orca 스크린 리더 — 추천 소프트웨어에서 설치, 또는 Ctrl+Alt+Space
  • 화면 확대경 — Ctrl+Alt+M으로 토글
  • UI 확대 — 환경설정 > Control Centre > Defaults 탭

새로 설치한 경우 최초 부팅 30초 후 음성 안내가 자동 재생됩니다.

파이썬 개발

apt로 시스템 패키지 설치

sudo apt install python3-<package>
# 예: sudo apt install python3-build-hat

pip와 가상환경

Raspberry Pi OS Bookworm부터는 "시스템 Python에 라이브러리를 직접 설치할 수 없습니다." 반드시 가상환경을 사용하세요.

# 프로젝트별 가상환경
python -m venv env
source env/bin/activate
(env) pip install <package>
(env) deactivate

# 사용자 레벨 가상환경
python -m venv ~/.env
source ~/.env/bin/activate

팁 - 가상환경에서 시스템 패키지도 쓰려면: python -m venv env --system-site-packages

기본 탑재된 파이썬 IDE인 Thonny에서는 우측 하단 메뉴로 인터프리터(가상환경)를 선택/구성할 수 있습니다.

Python으로 GPIO 제어

GPIO Zero 라이브러리를 사용합니다.

from gpiozero import LED
led = LED(17)
led.on()
led.off()

전체 문서: gpiozero.readthedocs.io
