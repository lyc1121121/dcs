Pico C SDK란?

Pico C SDK(Software Development Kit)는 RP2040/RP2350 기반 마이크로컨트롤러(Raspberry Pi Pico 시리즈)를 C/C++로 프로그래밍하기 위한 공식 라이브러리 모음입니다. 하드웨어 레지스터를 직접 다루는 저수준 하드웨어 API와, 그 위에 편의 기능을 얹은 고수준 API, 그리고 USB/블루투스/Wi-Fi 등을 위한 서드파티·네트워킹 라이브러리로 구성됩니다.

API 카테고리

  • 하드웨어 API (hardware_*)

    GPIO, I2C, SPI, PWM, ADC, 타이머, UART, DMA 등 칩 레지스터에 직접 대응하는 저수준 API. 35개 모듈로 구성.

  • 고수준 API (pico_*)

    표준 라이브러리 모음(pico_stdlib), 멀티코어(pico_multicore), 시간(pico_time), 동기화(pico_sync) 등 실무에서 자주 쓰는 편의 API.

  • 서드파티 라이브러리

    tinyusb(USB), mbedtls(암호화) 등 외부 오픈소스 라이브러리 통합.

  • 네트워킹 라이브러리

    btstack(블루투스), lwip(TCP/IP), cyw43(Pico W의 Wi-Fi 드라이버) 등.

  • 런타임 인프라

    부트스테이지, 표준입출력, 메모리 할당 등 실행 환경을 구성하는 저수준 인프라.

  • 외부 API 헤더

    부트 관련 헤더 파일 등 기타 참고 자료.

기본 예제

LED 깜빡이기(Blink) 같은 가장 기본적인 예제는 pico_stdlib(고수준 API)와 hardware_gpio(하드웨어 API)를 함께 사용합니다.

#include "pico/stdlib.h"

int main() {
    const uint LED_PIN = 25;
    gpio_init(LED_PIN);
    gpio_set_dir(LED_PIN, GPIO_OUT);
    while (true) {
        gpio_put(LED_PIN, 1);
        sleep_ms(250);
        gpio_put(LED_PIN, 0);
        sleep_ms(250);
    }
}
