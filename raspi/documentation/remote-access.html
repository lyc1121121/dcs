                            SSH

                            SSH 서버 활성화

                            • 데스크탑: 환경설정 > Control Centre > Interfaces 탭 > SSH 활성화
                            • OS 설치 중: Imager의 Remote Access 탭에서 SSH 토글
                            • 커맨드라인: sudo raspi-config > Interfacing Options > SSH > Yes
                            • 수동: sudo touch /boot/firmware/ssh 후 재부팅

                            SSH 서버 접속

                            ssh <username>@<ip address>

                            최초 접속 시 보안 경고를 수락한 뒤 비밀번호를 입력합니다.

                            키를 이용한 비밀번호 없는 SSH

                            # 키페어 생성
ssh-keygen

# 공개키를 Raspberry Pi로 복사
ssh-copy-id <username>@<ip address>

# 또는 수동으로 권한 설정 후 복사
mkdir .ssh
chmod 700 .ssh
scp .ssh/id_rsa.pub <username>@<ip address>:.ssh/authorized_keys
chmod 644 .ssh/authorized_keys

                            X11 포워딩(그래픽 앱을 SSH로)

                            ssh -Y <username>@<ip address>

                            SSH 접근 제한

                            /etc/ssh/sshd_config를 편집해 아래를 추가합니다.

                            AllowUsers alice bob
                            sudo systemctl restart ssh

                            VNC

                            VNC 서버 활성화

                            • 그래픽으로: 환경설정 > Control Centre > Interfaces 탭 > VNC 토글
                            • 커맨드라인: sudo raspi-config > Interface Options > VNC > Yes

                            VNC로 접속하기

                            1. TigerVNC를 GitHub 릴리스 페이지에서 다운로드
                            2. TigerVNC 실행 후 Raspberry Pi의 IP 주소 입력
                            3. Options > Input 탭 > "Show dot when no cursor" 체크
                            4. Connect 클릭, 인증서 경고가 나오면 수락
                            5. Raspberry Pi 계정 정보 입력

                            Raspberry Pi Connect

                            "IP 주소를 직접 찾거나 방화벽을 설정할 필요 없이" 다른 기기의 브라우저에서 Raspberry Pi Connect로 원격 접속할 수 있습니다. Wayland 시스템에서는 화면 공유를, 모든 모델에서는 원격 셸 접속을 제공합니다. 자세한 설정은 공식 Connect 문서를 참고하세요.

                            Raspberry Pi의 IP 주소 찾기

                            데스크탑: 시스템 트레이의 네트워크 아이콘에 마우스 올리기

                            # 커맨드라인
hostname -I

# mDNS(지원되는 경우)
ping raspberrypi.local

# Network Manager
nmcli device show   # IP4.ADDRESS[1] 필드 확인

# nmap 스캔
sudo nmap -sn 192.168.1.0/24

                            공유기: 공유기 관리 페이지에 로그인해 연결된 기기 목록을 확인

                            SCP로 파일 공유하기

                            SCP(Secure Copy Protocol, scp)는 SSH를 통해 파일을 전송합니다. Raspberry Pi와 다른 컴퓨터 사이에 파일을 복사할 때 사용합니다.

                            # 내 컴퓨터 -> Raspberry Pi
scp myfile.txt <username>@<pi_ip_address>:

# Raspberry Pi -> 내 컴퓨터
scp <username>@<pi_ip_address>:myfile.txt .

# 폴더 전체 복사(재귀)
scp -r project/ <username>@<pi_ip_address>:

                            rsync로 폴더 동기화하기

                            rsync는 컴퓨터 간 폴더를 자동으로 동기화합니다. "여러 번 실행해도 rsync가 이미 받은 파일을 기억해서 건너뜁니다" - 즉 변경된 부분만 다시 전송합니다.

                            rsync -avz -e ssh <pi_username>@<pi_ip_address>:<pi_folder_name>/ <pc_folder_name>/

                            네트워크 파일시스템(NFS)

                            NFS는 네트워크로 연결된 컴퓨터끼리 디렉터리를 공유합니다. "홈 디렉터리처럼 영구적으로 네트워크 마운트해두는 용도나, 자주 접근하는 공유 자원에 더 적합"합니다.

                            서버 설정

                            sudo apt install nfs-kernel-server
sudo mkdir -p /export/users
sudo mount --bind /home/users /export/users

                            /etc/fstab에 추가:

                            /home/users    /export/users   none    bind  0  0

                            /etc/exports에 추가:

                            /export       192.168.1.0/24(rw,fsid=0,insecure,no_subtree_check,async)
/export/users 192.168.1.0/24(rw,nohide,insecure,no_subtree_check,async)

                            클라이언트에서 마운트

                            sudo apt install nfs-common
mount -t nfs -o proto=tcp,port=2049 <nfs-server-IP>:/ /mnt

                            /etc/fstab에 추가:

                            <nfs-server-IP>:/   /mnt   nfs    auto  0  0

                            Samba(SMB/CIFS)

                            Samba는 Windows 등 SMB/CIFS 프로토콜을 쓰는 기기와 파일을 공유할 수 있게 해줍니다. Raspberry Pi를 Windows 탐색기에서 바로 보이는 파일 서버로 만들 때 주로 사용합니다.

                            sudo apt install samba samba-common-bin

                            자세한 공유 폴더 설정은 /etc/samba/smb.conf 편집이 필요합니다(원문 페이지 해당 절이 너무 길어 이번엔 개요만 옮김 - 상세 설정 필요하시면 말씀해주세요).

                            Apache 웹서버 설치

                            Raspberry Pi를 간단한 웹서버로 쓰고 싶을 때 Apache를 설치합니다.

                            sudo apt install apache2 -y

                            설치 후 브라우저에서 Raspberry Pi의 IP 주소로 접속하면 Apache 기본 페이지가 보이고, 웹 파일은 /var/www/html에 둡니다(원문 페이지 해당 절이 너무 길어 이번엔 개요만 옮김).

                            네트워크 부팅

                            SD카드 없이 네트워크(PXE)를 통해 운영체제를 부팅하는 방법입니다. 부팅 EEPROM에서 네트워크 부팅을 활성화한 뒤, TFTP/NFS 서버를 구성해 부트 이미지를 제공하는 방식입니다(IPv6 네트워크 부팅도 별도로 지원). 원문 페이지 해당 절이 매우 길어 이번엔 개요만 옮겼습니다 - 상세 절차가 필요하시면 말씀해주세요.
