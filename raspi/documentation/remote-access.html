                            SSH

                            SSH 서버 활성화

                            • 데스크탑: 환경설정 > Control Centre > Interfaces 탭 > SSH 활성화
                            • OS 설치 중: Imager의 Remote Access 탭에서 SSH 토글
                            • 커맨드라인: sudo raspi-config > Interfacing Options > SSH > Yes
                            • 수동: sudo touch /boot/firmware/ssh 후 재부팅

                            SSH 서버 접속

                            ssh <username>@<ip address>

                            최초 접속 시 보안 경고를 수락한 뒤 비밀번호를 입력합니다.

                            키를 이용한 비밀번호 없는 SSH

                            # 키페어 생성
ssh-keygen

# 공개키를 Raspberry Pi로 복사
ssh-copy-id <username>@<ip address>

# 또는 수동으로 권한 설정 후 복사
mkdir .ssh
chmod 700 .ssh
scp .ssh/id_rsa.pub <username>@<ip address>:.ssh/authorized_keys
chmod 644 .ssh/authorized_keys

                            X11 포워딩(그래픽 앱을 SSH로)

                            ssh -Y <username>@<ip address>

                            SSH 접근 제한

                            /etc/ssh/sshd_config를 편집해 아래를 추가합니다.

                            AllowUsers alice bob
                            sudo systemctl restart ssh

                            VNC

                            VNC 서버 활성화

                            • 그래픽으로: 환경설정 > Control Centre > Interfaces 탭 > VNC 토글
                            • 커맨드라인: sudo raspi-config > Interface Options > VNC > Yes

                            VNC로 접속하기

                            1. TigerVNC를 GitHub 릴리스 페이지에서 다운로드
                            2. TigerVNC 실행 후 Raspberry Pi의 IP 주소 입력
                            3. Options > Input 탭 > "Show dot when no cursor" 체크
                            4. Connect 클릭, 인증서 경고가 나오면 수락
                            5. Raspberry Pi 계정 정보 입력

                            Raspberry Pi Connect

                            "IP 주소를 직접 찾거나 방화벽을 설정할 필요 없이" 다른 기기의 브라우저에서 Raspberry Pi Connect로 원격 접속할 수 있습니다. Wayland 시스템에서는 화면 공유를, 모든 모델에서는 원격 셸 접속을 제공합니다. 자세한 설정은 공식 Connect 문서를 참고하세요.

                            Raspberry Pi의 IP 주소 찾기

                            데스크탑: 시스템 트레이의 네트워크 아이콘에 마우스 올리기

                            # 커맨드라인
hostname -I

# mDNS(지원되는 경우)
ping raspberrypi.local

# Network Manager
nmcli device show   # IP4.ADDRESS[1] 필드 확인

# nmap 스캔
sudo nmap -sn 192.168.1.0/24

                            공유기: 공유기 관리 페이지에 로그인해 연결된 기기 목록을 확인
