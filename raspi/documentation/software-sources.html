                            개요

                            Raspberry Pi는 제품용 오픈소스 코드를 공개하며, "3D·HEVC 디코드 같은 멀티미디어 가속, 카메라 이미징 파이프라인, AI 가속, 듀얼 HDMI, 오디오를 최적화하는 드라이버" 등 사용자 경험을 개선하는 소프트웨어에 중점을 둡니다.

                            Raspberry Pi OS에서 소프트웨어 소스 찾기

                            apt 설정 파일을 수정해 소스 패키지를 받아올 수 있습니다.

                            1. /etc/apt/sources.list.d/debian.sources(64비트), /etc/apt/sources.list.d/raspbian.sources(32비트) 또는 /etc/apt/sources.list.d/raspi.sources를 편집
                            2. "Types: deb"를 "Types: deb deb-src"로 변경
                            3. sudo apt update 실행
                            4. apt source [package-name]으로 소스 받기

                            Raspberry Pi OS 패키지는 Raspberry Pi 패치가 적용된 업스트림 소프트웨어인 경우가 많으며, 이런 패키지 버전에는 +rpt 태그가 붙습니다. 빌드하려면 devscripts 패키지와 debuild 등 일반적인 Debian 빌드 절차가 필요합니다.

                            GitHub 조직

                            Raspberry Pi는 소프트웨어 배포를 위해 3개의 주요 GitHub 조직을 운영합니다.

                            • github.com/raspberrypi
                            • github.com/raspberrypi-ui
                            • github.com/RPi-Distro

                            이 외에 출판물 관련 콘텐츠를 위한 조직도 별도로 운영합니다.

                            • github.com/raspberrypipress
                            • github.com/themagpimag

                            주요 저장소

                            핵심 소스 — Raspberry Pi 1~5용 리눅스 커널, 펌웨어(변경이력 포함 클로즈드소스), EEPROM 부트로더 설치 스크립트

                            라이브러리 & 애플리케이션 — GPIO 유틸리티, libcamera 구현체, 이미지 처리용 rpicam-apps, picamera2 파이썬 라이브러리, 멀티미디어 제어 라이브러리

                            데스크탑 — 데스크탑 메타패키지, 태스크바(Wayland/X 기반), 태스크바 플러그인(배터리/블루투스/시계/CPU/온도/파일꺼내기/GPU/메뉴/네트워크/전원/업데이트/볼륨), 파일 관리자, Control Centre 및 설정(화면/외관/입력장치/디스플레이/프린터) 플러그인

                            애플리케이션 — 진단 도구, Bookshelf 전자책 리더, SD Card Copier, 추천 소프트웨어 설치 도구

                            디버그 — 부팅 분석 서비스 도구

                            개발 도구 — Raspberry Pi Imager, 이미지 생성 시스템(rpi-image-gen), USB 부팅 유틸리티, 보안 부팅 프로비저너

                            피드백 — 현재 릴리스에 대한 버그 신고 저장소

                            Pico 개발 — VS Code 확장, SDK 설정 도구 및 소스, Debug Probe 펌웨어, OpenOCD 구현체, 예제 코드, BOOTSEL 모드 기기용 상호작용 도구
