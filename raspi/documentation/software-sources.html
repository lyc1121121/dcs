개요

Raspberry Pi는 제품용 오픈소스 코드를 공개하며, "3D·HEVC 디코드 같은 멀티미디어 가속, 카메라 이미징 파이프라인, AI 가속, 듀얼 HDMI, 오디오를 최적화하는 드라이버" 등 사용자 경험을 개선하는 소프트웨어에 중점을 둡니다.

Raspberry Pi OS에서 소프트웨어 소스 찾기

apt 설정 파일을 수정해 소스 패키지를 받아올 수 있습니다.

  1. /etc/apt/sources.list.d/debian.sources(64비트) 또는 /etc/apt/sources.list.d/raspbian.sources(32비트)를 편집
  2. "Types: deb"를 "Types: deb deb-src"로 변경
  3. sudo apt update 실행
  4. apt source [package-name]으로 소스 받기

빌드하려면 devscripts 패키지와 일반적인 Debian 빌드 절차가 필요합니다.

주요 저장소

핵심 소스 — Raspberry Pi 1~5용 리눅스 커널, 펌웨어(변경이력 포함 클로즈드소스), EEPROM 부트로더 스크립트/바이너리

라이브러리 & 애플리케이션 — GPIO 유틸리티/pinctrl 도구, 카메라 제어용 libcamera/rpicam-apps, picamera2 파이썬 라이브러리, drmu 멀티미디어 라이브러리

데스크탑 환경 — 데스크탑 메타패키지, 태스크바, 파일 관리자, Control Centre 및 설정 플러그인, 진단도구, Bookshelf, SD Card Copier 앱

개발 도구 — Raspberry Pi Imager, rpi-image-gen 빌드 시스템, usbboot 프로비저닝 도구, 보안 부팅 프로비저너

Pico 개발 — Visual Studio Code 확장, Pico SDK 및 예제, Debug Probe 펌웨어, OpenOCD 다운스트림 소스
