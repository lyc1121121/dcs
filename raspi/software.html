Raspberry Pi 소프트웨어

운영체제부터 GitHub 저장소까지, Raspberry Pi 기술을 움직이는 소프트웨어를 살펴보세요.

Raspberry Pi Imager

Raspberry Pi Imager는 Raspberry Pi OS 및 기타 운영체제를 microSD 카드에 설치해 바로 Raspberry Pi에서 사용할 수 있게 해주는 가장 빠르고 쉬운 방법입니다. Windows/macOS/Linux 및 Raspberry Pi OS 자체에서 터미널로 설치할 수 있는 안내도 제공됩니다.

Raspberry Pi Connect

간편 원격 접속 — 브라우저 하나로 전 세계 어디서든 무료로, 별도 설정 없이 Raspberry Pi에 접속할 수 있습니다.

플릿 관리 — 배포한 모든 장치에 대한 원격 접속·원격 업데이트, 검색 가능한 장치 인벤토리, 조직 단위 감사 로그를 제공합니다.

Raspberry Pi OS

Raspberry Pi OS는 공식 운영체제입니다. 사내 소프트웨어 엔지니어링 팀이 지속적으로 업데이트하며, 모든 Raspberry Pi 컴퓨터에 대한 하위 호환성을 제공합니다 - Raspberry Pi 5든, 최초의 Raspberry Pi 1이든, 어떤 모델을 쓰든 완전히 최적화된 OS를 누릴 수 있습니다.

Raspberry Pi Pico 개발

MicroPython — Raspberry Pi Pico 시리즈 마이크로컨트롤러에서 직접 실행되는 Python 3의 완전한 구현체입니다.

C/C++ — 파워 유저와 전문 개발자를 위해 완전한 C/C++ SDK와 Visual Studio Code 통합을 제공합니다.
